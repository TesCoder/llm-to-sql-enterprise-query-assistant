About the dataset

            

              This dataset is a retail “Superstore Sales” dataset. Each row represents a product line item on an order,
              and it includes:
            

            
    
              
  • Orders: Order ID, Order Date, Ship Date, Ship Mode
    • 
              
  • Customer: Customer ID, Customer Name, Segment
    • 
              
  • Geography: Country, City, State, Postal Code, Region
    • 
              
  • Product: Product ID, Category, Sub-Category, Product Name
    • 
              
  • Metric: Sales
    • 
            

          


          

            
Try questions like

            
    
              
  • “Which region has the highest total sales?”
    • 
              
  • “Show total sales by category”
    • 
              
  • “What are the top 10 states by sales?”
    • 
              
  • “Show total sales by month”
    • 
            

          


          

            
Where is it stored?

            

              enterprise.db
              SQLite
            

            
Behind the scenes it’s stored in two tables:

            

              

                
orders

                
Order dates, shipping, customer, and location

                

                  Fields (dev)
                  
order_id (PK), order_date, ship_date, ship_mode, customer_id, customer_name, segment, country, city, state, postal_code, region

                

              

              

                
order_items

                
Products (category/sub-category) and sales amount

                

                  Fields (dev)
                  
row_id (PK), order_id (FK → orders.order_id), product_id, category, sub_category, product_name, sales

                

              

            

          


          

            
Joins (dev)

            
`order_items.order_id` → `orders.order_id`

          


          

            
Notes (dev)

            
    
              
  • Dataset file: data/train.csv
    • 
              
  • All queries are SELECT-only; a default LIMIT is applied if missing.
